# Licensing map — per directory

The repository is NOT a single-license work. This file states exactly what is
licensed how, and where third-party terms apply.

| Path | License | Notes |
|---|---|---|
| `/` (first-party code: `contracts/*` except the fork, `frontend/`, `agent/`, `circuits/src`, `circuits/ark-verifier`, `disclosure/`, `scripts/`, docs) | MIT (root `LICENSE`) | Copyright (c) 2026 Writ |
| `contracts/writ-cep78/fork/` | **Apache-2.0** | Vendored fork of `casper-ecosystem/cep-78-enhanced-nft` v2.0.0 (`9a624aa`) with the recipient-aware patch. Full text in `fork/LICENSE`; attribution + modification list in `contracts/writ-cep78/NOTICE`. |
| `frontend/public/circuit/eligibility.wasm` | **GPL-3.0** (generated artifact) | Witness calculator generated by the `circom` compiler (GPL-3.0) from `circuits/src/eligibility.circom`, which includes `circomlib` templates (GPL-3.0). The artifact is a derivative of GPL-licensed template code and is distributed under GPL-3.0; its complete corresponding source is `circuits/src/eligibility.circom` + the pinned `circomlib` dependency (`circuits/package.json`), and the regeneration commands are in `circuits/README.md`. |
| `frontend/public/circuit/elig2_final.zkey`, `elig2_vkey.json` | data outputs | Proving/verifying key material produced by `snarkjs` (GPL-3.0 tool) from the single-contribution dev ceremony documented in `circuits/README.md`. Key material is ceremony output data, not program code. **Demo-grade — see the trusted-setup caveat.** |
| `frontend/tests/fixtures/` | data outputs | A Groth16 proof + its ark-serialized bytes, committed as public test fixtures (no secrets). |
| npm / cargo dependencies | their own licenses | Notably `snarkjs` and `circomlib` are GPL-3.0 and are used as build/runtime dependencies; `arkworks` crates are MIT/Apache-2.0; Odra is MIT. |

Why the generated circuit artifacts are committed at all: the live frontend
serves them for in-browser proving, and judges reproducing from a clean clone
would otherwise need the full circom toolchain before the app runs. Anything in
`circuits/build/` stays gitignored and regenerable.
